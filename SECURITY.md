# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability within PromptManifold, please report it responsibly by contacting the maintainers at security@promptmanifold.dev or opening a confidential security advisory on GitHub.

Please include:
- Description of the potential vulnerability.
- Steps or proof of concept to reproduce the issue.
- Potential impact and severity assessment.

We strive to acknowledge receipt of all vulnerability reports within 48 hours and provide remediation timelines promptly.
